使用與計算說明

加入 iPhone 主畫面

  1. 用 Safari 開啟這個網站。
  2. 點「分享」，選「加入主畫面」。如有「以網頁 App 開啟」選項，將其開啟。
  3. 名稱可保留「NS 流速」，點「加入」。
  4. 從主畫面開啟一次並等待下方顯示「已可離線使用」，再測試關閉網路。

首次開啟需連線，離線快取需 HTTPS 或 localhost。瀏覽器清除網站資料後，需重新連線下載。

各班流速先四捨五入至整數，再乘各班剩餘時間；因此總量可能有差額。已結束的班別計 0 小時，尚未開始的班別計完整 8 小時。

「總剩餘劑量」表示目標尚需輸入的量。「預計輸入劑量」為三班目前設定流速乘以剩餘小時的加總，含手動固定與自動連動的班別；未套用的輸入不計入。

交班時這袋 NS 剩多少

每天 08:00 從一袋 500 mL 滿袋開始，假設每袋輸完後接續換新袋。交班袋數表示目前這袋的剩餘量，並非每日目標尚未輸入的總袋數。

先累計到 16:00 或 24:00 的輸入量，再以每袋 500 mL 計算這袋剩餘量。例如累計 656 mL 時，第二袋已輸入 156 mL，剩 344 mL（0.688 袋）。若交班時剛好輸完，顯示 0 mL 並提醒換新袋。已經過的交班點只能依變更前流速回推，不是實際紀錄。

手動固定與自動分配

輸入小數後按「套用流速」才生效。修改某班會固定該班；其他自動班別重新計算。所有班別都固定時，保留設定並顯示差額。可點「恢復自動」解除固定。

流速滑桿每格增減 5 mL/hr。各班滑桿以當前整數流速為基準，數字欄位仍可微調；自動流速不強制取 5 的倍數。目前流速滑桿範圍為 5–500 mL/hr。

修改主要輸入會清除手動設定與未套用的輸入。重新開啟網頁會恢復預設值，請重新核對輸入。

計算範圍

本工具試算輸注量與時間，不判斷醫囑適當性。流速滑桿會隨所需流速延伸，500 mL/hr 並非輸出流速的安全上限。無可分配量時顯示 0，不代表停液醫囑。

以單位一致、未固定班別共同分配為目前公式假設；正式使用前需確認符合院內流程。
