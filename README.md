# NS 流速 · HTML 網頁 App

純 HTML、CSS、JavaScript，不需要 npm 安裝依賴或建置。適合 iPhone Safari，具備 Web App Manifest、主畫面圖示、Service Worker 離線快取與響應式介面。

## 在 iPhone 使用

以 Safari 開啟部署後的 HTTPS 網址，點分享 → 加入主畫面。如果顯示「以網頁 App 開啟」，將其開啟。從新圖示首次開啟仍需連線，並等待頁尾顯示「已可離線使用」，再用飛航模式驗證。詳細操作見 [Apple 官方說明](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios)。

離線快取只存程式與圖示，不存輸入值。重新開啟頁面會恢復 80 mL/hr、4 袋、12:00 的預設條件。Safari 與主畫面 App 的網站資料可能分開，請在主畫面 App 內確認離線就緒。清除瀏覽器網站資料或儲存空間遭系統回收時，需重新連線下載；離線不是永久儲存保證。

## Windows 開發與預覽

需要 Node.js 18 以上。於本目錄執行：

```powershell
npm start
```

電腦瀏覽器開啟 `http://127.0.0.1:8080`。預覽伺服器預設只綁定本機，手機無法使用電腦的 `127.0.0.1`。部署至 HTTPS 靜態網站即可在 iPhone 開啟。

雙擊 `dist/index.html` 可在桌面瀏覽器檢視與計算，但 `file://` 不支援本專案的離線 Service Worker；加入 iPhone 主畫面應使用網站網址。

## 計算與操作

每袋 500 mL；修正前袋數為目前流速 × 24 ÷ 500。所有自動班別共同分配剩餘量。修改某班後固定該班，其餘自動班別依剩餘量重新分配。流速四捨五入至整數後計算總量，差額保留。完整公式與待確認的假設見專案根目錄 README。

流速輸入框接受小數，按「套用流速」或鍵盤 Enter 生效；未套用的內容不參與計算。可取消編輯；修改主輸入或其他班別後會清除未套用草稿。所有輸出流速滑桿從 0 起且會延伸上限，以便呈現所需流速；未套用通用臨床流速閾值。計算目標已達成或已超出時顯示 0，並非停液醫囑。

無第三方 JavaScript、字型或統計追蹤。計算在瀏覽器內完成，不將輸入值傳送到伺服器。本工具不判斷醫囑適當性，也不控制輸液設備。

## 發布

可將 **`dist` 資料夾內的所有檔案與子資料夾**部署到支援 HTTPS 的靜態網站服務。所有程式資源使用相對路徑，亦支援例如 `/ns-flow/` 的子路徑。不需要伺服器端程式或資料庫。

Sites 的靜態來源設定位於 `.openai/hosting.json`，既有 `project_id` 需保留。網站已依使用者要求改為公開存取，任何持有網址的人都可使用，不需登入；已確認匿名請求返回 HTTP 200 計算頁且無登入轉址。權限由 Sites 管理設定控制，毋須修改 HTML。若要改用其他主機，直接發布 `dist` 即可。

**更新任一程式資源時，需遞增 `dist/sw.js` 的 `CACHE` 版本。** 新版本會先在背景下載，頁尾顯示「更新版本（重設輸入）」；使用者點擊後才載入新版本，避免同一頁混用不同版本的公式與畫面。v2 修復版在偵測到 v1 快取時會自動接管，以修復舊版無法開啟更新介面的問題；不強制重載正在輸入的頁面。

主機的 `index.html` 會轉址至首頁。v2 改為快取直接回傳的首頁，並在導航時清除快取回應的轉址標記，避免瀏覽器因導航轉址模式與快取不相容而顯示 `ERR_FAILED`。快取無法讀取時會回到網路載入。

## 測試紀錄

```powershell
npm test
```

已通過 31 個 Node.js 測試，包括 18 項計算測試（其中涵蓋 3,600 組輸入邊界）、7 項 manifest / 圖示 / Service Worker 測試、6 項執行實際 `app.js` 事件處理的 DOM 模型測試。測試包含零剩餘時間、跨午夜、目標超量、手動小數四捨五入、各班互調、主要輸入重設、錯誤文字、離線快取、轉址回應相容性、v1 修復更新及快取失敗後的線上載入。

本地 HTTP 預覽返回 200，`app.js` 與 `sw.js` 的 JavaScript 語法檢查通過。本環境沒有可用的瀏覽器，**未驗證真實瀏覽器排版、iPhone Safari、加入主畫面或實機飛航模式**；DOM / Service Worker 模型測試不能替代這些驗證。正式使用前需確認公式假設符合需求與院內流程。
